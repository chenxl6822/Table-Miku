### 2.2 对话气泡增强 — 解决"显示时间短、长文不全"

**当前问题：**
- 气泡固定 300×86，最大 142px 高度
- 默认 7 秒自动隐藏，长文本 10 秒保底
- 文本超出溢出，不可滚动/展开

**改造方案：**

| 改进点 | 实现方式 |
|--------|---------|
| **弹性停留** | 改为 `max(8, text_len × 0.3 秒)` = 10 字约 3s，100 字约 30s，上限 60s |
| **可点击固定** | 用户点击气泡 → 暂停倒计时，气泡保持显示 |
| **长文显示模式** | >120 字时弹出独立对话框（带滚动条、关闭按钮、全文本显示） |
| **气泡高度自适应** | 取消上限 142，根据行数动态增高，最高不超过 240px |
| **配置可调** | 设置菜单新增气泡配置：显示时长倍率、字号、透明度 |

**气泡交互设计：**
```
┌─────────────────────────────────────┐
│  今日任务已打开。先挑最小的一项开始  │
│  吧。你有 3 个目标和 2 门课程。      │
│          [已读 ✓]                    │
└─────────────────────────────────────┘
    ↑ 点击气泡内容 → 暂停倒计时
    ↑ 点击 [已读] → 立即隐藏
    ↑ 长文本自动弹出详情框
```

**改动文件：**
- `app.py` — `say()`、`_bubble_text()` 逻辑改造
- `PetScene.qml` — `showBubble()` 增加高度自适应、点击处理
- `app.py` — 新增 `BubbleDetailDialog` 长文独立窗口

### 2.3 恶劣天气预警 — 解决"天气提醒缺失"

**现有能力：**
- `weather.py` 已有 `get_weather()`、`check_bad_weather()`、支持 rain/snow/wind
- 已有 `ReminderManager` 定时心跳框架

**新增：`WeatherMonitor` 独立轮询服务**

```
WeatherMonitor (30 分钟轮询)
  ↓
天气数据获取 (wttr.in / OpenWeather API)
  ↓
检查恶劣条件：
  ├ 下雨/雪概率 ≥ 60% → "预计 30 分钟后将下雨，记得带伞 🌂"
  ├ 大风 > 20km/h → "风比较大，出门注意防风 🍃"
  ├ 高温 > 35°C → "今天很热，注意防暑 ☀️"
  ├ 低温 < 0°C → "零下了，多穿点 🥶"
  └ 紫外线强 → "紫外线强度高，注意防晒 🧴"
  ↓
提前时间可配置（默认 30 分钟）
  ↓
触发时：Miku 弹出提醒 + 动作/表情变化
```

| 组件 | 文件 | 作用 |
|------|------|------|
| 预警轮询 | `weather_monitor.py` (新建) | 独立 QTimer 轮询，检查未来天气 |
| 条件判定 | 同上 | 多种天气条件阈值判定 |
| 提醒推送 | 通过 `reminder` signal 或 `say()` | 复用现有气泡系统 |
| 配置项 | `settings.json` 扩展 | `weather_alert_lead_minutes: 30` |
| 集成入口 | `app.py` `__init__` | 初始化 WeatherMonitor |

**改动文件：**
- 新建 `table_miku/weather_monitor.py`
- `app.py` — 集成 WeatherMonitor
- `docs/` — 配置文档更新

```
  - settings.json: bubble_duration_multiplier, bubble_font_size, bubble_opacity

say() 新逻辑：
  def say(self, text):
    base_seconds = max(8, len(text) * 0.3)  ← 弹性时长
    capped_seconds = min(base_seconds, 60)
    if len(text) > 120:
      show_bubble("(点击查看完整内容 ↕️)", capped_seconds)
      # 同时弹出详情框（非模态，可关闭）
      BubbleDetailDialog(text, self).show()
    else:
      show_bubble(self._format_bubble(text), capped_seconds)
```

```
  - _check_alerts(): 检查 30 分钟后的恶劣条件 → 信号发送

集成到 app.py：
  __init__:
    self.weather_monitor = WeatherMonitor(self)
    self.weather_monitor.weather_alert.connect(self.say)
```
